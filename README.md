# Al-Mu'allim: AI Quran Academy 🕌

An advanced, interactive Python web application built using Streamlit to help users read, study, and memorize the Quran with vowel-level audio feedback tracking.

## Features
- **Interactive AI Classroom:** Natively captures recitation audio directly through the web browser without iframe recording freezes.
- **Phoneme & Vowel Analysis:** Simulates precision evaluation of Harakat (Fathah, Dammah, Kasrah) and terminal elongation metrics.
- **Integrated Tafsir Workspace:** Side-by-side study panel featuring classical Tafsir al-Muyassar text updates directly from live API sources.
- **Classical Hifdh Progress Tracker:** Built-in dashboard to monitor daily Sabaq, Sabqi, and Manzil progression targets.

## Deployment & Hosting
This application runs on a server-driven backend and is actively deployed on **Streamlit Community Cloud**. 

### Local Setup
If you want to run this application locally on your machine:
1. Clone this repository.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   streamlit run app.py
   ```
